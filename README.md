# 🐍 Primeiro Programa em Python

Projeto introdutório desenvolvido em **Python** para praticar a criação e execução de um arquivo, o uso da função `print()` e o versionamento de código com Git e GitHub.

## 📖 Sobre o Projeto

Este repositório contém um programa simples que apresenta uma mensagem no terminal.

O código atual é:

```python
print("teste")
```

Apesar de pequeno, o projeto representa uma etapa inicial importante no aprendizado de programação e no uso das ferramentas de desenvolvimento.

## 🎯 Objetivos

Este projeto foi desenvolvido com os seguintes objetivos:

* Criar um arquivo Python;
* Conhecer a extensão `.py`;
* Utilizar a função `print()`;
* Executar um programa no terminal;
* Praticar o uso do Visual Studio Code;
* Criar um repositório no GitHub;
* Enviar arquivos para o controle de versão;
* Compreender a estrutura inicial de um projeto.

## 🧠 Funcionamento

A função `print()` é utilizada para apresentar informações na tela.

Exemplo:

```python
print("teste")
```

Ao executar o programa, o terminal apresenta:

```text
teste
```

## 🚀 Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/ewertonmartinslopes/python-primeiro-programa.git
```

### 2. Acesse a pasta

```bash
cd python-primeiro-programa
```

### 3. Verifique a instalação do Python

```bash
python --version
```

### 4. Execute o programa

```bash
python index.py
```

Em alguns sistemas, utilize:

```bash
python3 index.py
```
